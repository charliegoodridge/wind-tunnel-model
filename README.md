Overview
Model built around A5 window inserts and a 120x120mm fan with parametric design for scalable alterations. Push-fit tolerances 

Components:
- Main body
- Observation cover
- Intake funnel
- Honeycomb
- Fan mount

BOM:
- 120x120mm USB fan
- PLA filament for 3d printing
- 2 x A5 3mm thick Perspex inserts
- Mist maker


Current status: awaiting 3d printing  

Future plans are to test, collect and analyse data using test objects.
